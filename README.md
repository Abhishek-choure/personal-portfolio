# Abhishek Choure — Portfolio

A responsive portfolio website built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — blue-violet theme, cards, responsive layouts, and animations
- `script.js` — mobile navigation, reveal effects, active navigation, and contact form validation

## Run
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use VS Code Live Server.

## Before submitting
- The portrait area is a placeholder showing `AC`. Replace it with your own photo if your internship brief requires one.
- Verify your phone number, email, LinkedIn and GitHub links.
- Keep project descriptions accurate; only claim work you can demonstrate.
- The contact form validates the inputs and opens the visitor's email app. It does not send or store messages through a backend.
- A real CV download needs a PDF file and a link to that file; this design currently uses the Contact section instead of a fake download.
